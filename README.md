## 📖 Sobre o projeto

O SQL Server DBA Toolkit é uma coleção de scripts T-SQL voltados à administração, sustentação, monitoramento e diagnóstico de ambientes Microsoft SQL Server.

O projeto tem como objetivo reunir consultas úteis para o dia a dia de um DBA, acompanhadas de documentação técnica, orientações de utilização e interpretação dos resultados.

## 🎯 Objetivos

- Facilitar o diagnóstico de ambientes SQL Server.
- Apoiar a investigação de incidentes.
- Identificar possíveis gargalos de performance.
- Auxiliar no monitoramento de recursos.
- Documentar boas práticas de administração de bancos de dados.
- Compartilhar conhecimento com a comunidade.

## ⚙️ Requisitos

- Microsoft SQL Server.
- SQL Server Management Studio (SSMS) ou ferramenta compatível.
- Permissões adequadas para execução das consultas.

Os requisitos específicos de versão e permissões serão documentados individualmente em cada script.

## ⚠️ Recomendações de segurança

- Avalie os scripts antes de executá-los.
- Priorize testes em ambientes de laboratório.
- Considere o impacto das consultas em produção.
- Utilize apenas as permissões necessárias.
- Não compartilhe informações sensíveis dos ambientes analisados.

Todos os exemplos deste repositório utilizam informações genéricas ou fictícias, sem exposição de dados corporativos.
